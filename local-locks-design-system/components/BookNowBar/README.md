# BookNowBar

One large **Book Now** at the top of a main page, so the way in is never a hunt. It is a `Button` at size `lg` (3.5rem tall, 1.15rem text, `gold-ink` fill, white text at 6.3:1), full width on a phone and capped at 24rem from there.

- Used at the top of Stylists, a stylist's profile, Saved, and My appointments. Home has its own in the hero, and the Book page is already booking.
- On a profile it reads "Book Now with London" and books with her; elsewhere it opens the Book page.
- It adds no second action color, no badge, and no motion: calm, just easy to find.
