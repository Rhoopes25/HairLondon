# MapCard

Where her chair is: a simple drawn map with a `gold-ink` pin, the address with a map-pin icon, an optional distance ("2.1 mi away", once she shares her location), and an outline "Get directions" pill.

The map is a sketch, not a live map, on purpose: it loads instantly, never breaks, and stays in the prototype's low-fidelity look. Land is `cream-deep`, roads `white`, water `gold-soft`, a park `photo-light`. "Get directions" opens Google Maps directions in a new tab (on a phone, it hands off to the maps app), and says so to screen readers.

Used on the About me tab of a profile and on the About the studio page. Addresses in the sample data are made up, and the About me tab says so.
